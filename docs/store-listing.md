## Комментарий для модерации

```text
Десктоп: управление клавиатурой и мышью, клавиши по физическому положению — раскладка не важна. Мобильные: любая ориентация, плавающий джойстик в любой точке экрана и кнопки навыка, ульты, рывка и паузы; навык наводится на ближайшего врага автоматически. Язык определяется по ysdk.environment.i18n.lang (русский или английский), в меню есть ручной переключатель. Прогресс сохраняется сразу: покупки в мастерской, открытия и достижения — в момент действия, итоги забега — по его окончании; облако через player.setData. Реклама: полноэкранная только между забегами по кнопке «Ещё раз» / «В меню»; за награду — по отдельной кнопке на экране итогов (дополнительные осколки) и на экране «Последний шанс» (воскрешение, один раз за забег). Вход через Яндекс — по кнопке в главном меню с объяснением преимуществ, без входа игра полностью доступна.
```
