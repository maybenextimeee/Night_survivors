# Релиз на Яндекс Игры — памятка

Всё, что нужно сделать руками, по порядку. Код к модерации готов: SDK, облачные сохранения,
вход через Яндекс, таблица рекордов, реклама (между забегами, за награду, за воскрешение),
удалённая конфигурация, русский и английский, управление с телефона, пауза при потере фокуса.

Текущая версия игры — **0.9.0**. Она видна в правом нижнем углу меню и записана в [CHANGELOG.md](../CHANGELOG.md).
Перед первой отправкой на модерацию её стоит поднять до **1.0.0**.

## 1. Аккаунт и договор — начни с этого, тут дольше всего ждать

1. Зайди в [Консоль разработчика](https://games.yandex.ru/console) со своим Яндекс ID и создай профиль.
   В профиле укажи предпочитаемый язык связи.
2. Без договора игру **нельзя отправить на модерацию** (черновик заполнить можно). Варианты:
   - ИП или юрлицо в России — договор прямо в Консоли;
   - физлицо — регистрация в РСЯ (Рекламной сети Яндекса) как **самозанятый** или ИП.
3. Проверка документов — около 3 рабочих дней. Модерация самой игры — ещё 3–5.

## 2. Собрать архив

```powershell
./build.ps1
```

Готовый архив — `build/night-survivors-yandex.zip`, его и загружаешь в черновик.
В архиве один `index.html` в корне, внутри уже подключён SDK (`/sdk.js`, относительный путь — так требует Яндекс).
Папка `build/` в git не попадает.

Локально эта сборка SDK не найдёт (404 на `/sdk.js` в консоли — это нормально) и работает как обычная версия.

## 3. Лидерборды — создать в Консоли до отправки

Вкладка **Лидерборды**, три штуки. Технические названия — ровно такие, иначе запросы будут падать с 404:

| Техническое название | Название (RU / EN) | Тип | Сортировка |
|---|---|---|---|
| `endlessQuarter` | Бесконечность · Неоновый квартал / Endless · Neon Quarter | Время | по убыванию (больше — лучше) |
| `endlessFoundry` | Бесконечность · Литейный цех / Endless · The Foundry | Время | по убыванию |
| `endlessCore` | Бесконечность · Ядро сети / Endless · Network Core | Время | по убыванию |

Результат игра отправляет в миллисекундах — для типа «время» так и нужно.

## 6. Промоматериалы

| Материал | Требования | Обязательно |
|---|---|---|
| Иконка | 512×512, PNG. **Нельзя скриншот из игры** (пункт 5.6) | да |
| Обложка | 800×470, PNG. Тоже не скриншот | да |
| Скриншоты | минимум **по 2 на каждую платформу** (десктоп и мобильные), 16:9, от 1280 до 2560 px по длинной стороне. Геймплей — не меньше 70% кадра | да |
| Горизонтальное видео | 16:9, MP4, до 28 секунд, высота от 400 px. Геймплей — не меньше 70% времени | да |
| Обложка на витрину | 1560×520 — для подборок | нет |

Если иконку и обложку делаешь с надписью — на английском черновике нужна английская версия
картинок (или делай их вообще без текста, тогда одни подойдут обоим языкам).

Скриншоты для десктопа: окно 1920×1080 (F11, потом Win+Shift+S). Для мобильных — открой игру

Видео — Xbox Game Bar (Win+G) или OBS. На иконке и обложке без рамок и скруглённых углов (пункт 8.3.3).

## 7. Удалённая конфигурация (флаги)

Флаги меняют поведение уже опубликованной игры **без нового архива и без модерации**:
изменения доезжают до игроков за несколько секунд. Игра запрашивает их один раз при запуске.

### Как завести флаг

1. Консоль → твоя игра → вкладка **Флаги** → **Добавить флаг**.
2. **Название** — одно из таблицы ниже, буква в букву. **Значение по умолчанию** — строка.
3. При желании **Добавить значение** с условием: язык, регион, платформа (мобильные / десктоп).
   На каждый флаг — одно значение по умолчанию и до двух с условиями.
4. **Сохранить**, затем **Опубликовать конфиг** → **Сохранить**. Всё, игроки получат новое значение
   при следующем запуске. Если что-то пошло не так — там же можно откатиться на прошлую версию.

### Какие флаги понимает игра

| Флаг | По умолчанию | Допустимо | Что делает |
|---|---|---|---|
| `xp_mul` | `1` | 0.25 – 4 | множитель опыта |
| `shard_mul` | `1` | 0.25 – 5 | множитель осколков за забег |
| `enemy_hp_mul` | `1` | 0.25 – 4 | множитель здоровья врагов |
| `enemy_dmg_mul` | `1` | 0.25 – 4 | множитель урона врагов |
| `chest_every` | `45` | 15 – 120 | интервал сундуков до 10:00, секунды |
| `reward_mul` | `1` | 0 – 5 | сколько ещё «итогов забега» даёт реклама за награду (1 = удвоение) |
| `ad_between_runs` | `1` | `0` / `1` | полноэкранная реклама между забегами |
| `ad_revive` | `1` | `0` / `1` | предлагать воскрешение за рекламу |
| `revive_hp` | `0.5` | 0.1 – 1 | с какой долей здоровья поднимает воскрешение |
| `news` | пусто | до 100 символов | строка-объявление в главном меню |

Значения за пределами диапазона игра обрезает до ближайшей границы, а мусор вроде `abc` игнорирует —
опечатка в Консоли не сломает игру у всех игроков разом.

### Примеры

- **Выходные с двойными осколками.** `shard_mul` = `2`, `news` = `Двойные осколки все выходные!`.
  Для английского добавь к `news` значение с условием «Язык: английский» — `Double shards all weekend!`.
  В понедельник верни `shard_mul` = `1`, `news` = пусто.
- **Новички жалуются на сложность.** `enemy_hp_mul` = `0.85` — враги на 15% мягче, без обновления игры.
- **На телефонах реклама мешает.** Добавь к `ad_between_runs` значение `0` с условием «Платформа: мобильные».

## 8. Проверить перед отправкой

В Консоли нажми **Открыть с debug-панелью** и пройдись по списку:

- [ ] в левом нижнем углу индикатор лоадера показывает **IT** — SDK подключён правильно;
- [ ] меню открывается, `LoadingAPI.ready` уходит (debug-панель это показывает);
- [ ] через **SDK mocks ⚒️** выбери английский — игра открылась на английском;
- [ ] свернул вкладку посреди забега — звук замолчал, забег на паузе;
- [ ] начал забег на русской раскладке — WASD работают;
- [ ] правая кнопка мыши нигде не открывает контекстное меню;
- [ ] сыграл забег, обновил страницу — осколки и открытия на месте;
- [ ] вошёл через кнопку в меню — имя появилось в досье, прогресс не потерялся;
- [ ] включил «Бесконечность» на пройденной арене — снизу открылась таблица рекордов;
- [ ] умер — предложили воскрешение за рекламу; после ролика поднялся; второй раз не предлагают;
- [ ] на экране итогов кнопка рекламы за награду показывает ролик и даёт осколки;
- [ ] «Ещё раз» и «В меню» иногда показывают полноэкранную рекламу, звук на это время молчит;
- [ ] уменьшил окно браузера — ничего не налезает друг на друга;
- [ ] **с телефона** (или в DevTools в режиме телефона): джойстик ведёт героя, кнопки работают,
      меню влезает без прокрутки, длинное нажатие ничего не выделяет;
- [ ] в консоли DevTools нет красных ошибок (кроме самого Яндекса).

## Что важно помнить после публикации

- Рейтинг игры должен держаться **выше 30** — если три недели он 30 и ниже, игру снимут (пункт 2.13).
- Первую неделю игра будет в разделе «Новые», через две недели на карточке появится рейтинг.
- Обновления — новым архивом в черновике, с новой версией; концепцию игры менять нельзя (пункт 1.24).
  Баланс и рекламу можно крутить флагами без обновлений — см. раздел 7.
- Сайт на GitHub Pages продолжает работать как раньше: там та же игра, только без SDK — сохранения
  локальные, таблица рекордов личная, рекламы и флагов нет.
